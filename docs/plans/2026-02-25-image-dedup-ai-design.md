# 图片去重功能优化设计文档

## 概述

在现有的 pHash 去重基础上，增加 AI 特征相似度检测，实现 pHash + AI 组合去重。

## 优化背景

- pHash 只能检测完全相同或非常相似的图片
- AI 特征向量可以识别同一场景不同角度的相似图片
- 组合使用可以更智能地过滤重复图片

## 技术方案

### 1. 工作流程

```
收到新图片
    ↓
计算 pHash → 与缓存比较
    ↓                ↓
  相似(≤阈值)      不相似
    ↓                ↓
  直接过滤        ↓
              计算 AI 特征向量
                  ↓                  ↓
            相似(≥阈值)           不相似
                  ↓                  ↓
              过滤              加入缓存 + 计数
```

### 2. AI 特征提取

使用 MobileNet V2 模型提取特征向量：
- 移除最后的分类层，获取 1280 维特征向量
- 计算两个向量的余弦相似度

### 3. 缓存结构优化

```rust
struct DedupCache {
    p_hash: String,           // pHash 值
    ai_feature: Vec<f32>,    // AI 特征向量
    url: String,              // 图片 URL
}
```

## 配置项

| 环境变量 | 说明 | 默认值 |
|---------|------|-------|
| APP_P_HASH_THRESHOLD | pHash 相似度阈值(汉明距离) | 5 |
| APP_AI_SIMILARITY_THRESHOLD | AI 特征相似度阈值(余弦相似度) | 0.95 |

## 实现步骤

1. 扩展 PersonDetector，添加特征向量提取功能
2. 修改 ImageDedup，同时存储 pHash 和 AI 特征
3. 实现组合去重逻辑
4. 添加新的环境变量配置

## 注意事项

- pHash 计算快，用于快速过滤
- AI 特征用于二次确认，提高准确性
- 两个检测是串行的，先 pHash 后 AI
